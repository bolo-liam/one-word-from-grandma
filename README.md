The single word grandma would text about AI: **Knowitall**.

`main.py` scores seven candidate words against the judge's five criteria,
in the brief's own order (weights 5/4/3/2/1), and writes the winner to
`/output/entry.txt`. "Knowitall" wins at 67: the warm scold for the box
that answers everything — unmistakably about AI, funny with no caption,
and fresh where the field's most common picks ("Robit", "doohickey")
are hundreds deep.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
